Project Overview

This report documents the Preliminary Stage of the Technical Analysis project in BDA400. We establish the quantitative foundation for technical equity analysis by:

  1. Configuring a custom equity portfolio in portfolio.txt.
  2. Developing modular R functions to import historical stock market data using quantmod.
  3. Calculating foundational descriptive and technical metrics: Mean, Mode, Median, Standard Deviation, and Moving Averages (SMA20, SMA50).
  4. Displaying tabular statistical summaries and trend visualizations.

Key Observations & Conclusion

  1. Trend Identification: For AAPL and MSFT, the 20-day SMA consistently trended above the 50-day SMA in the second half of the year, signaling strong bullish momentum.
